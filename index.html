AI에 넣은 내용은 학교 밖 서버로 나갑니다. 아래 자료를 하나씩 판단해 보세요.

이 분류는 연수용 예시입니다. 소속 법인과 학교의 지침을 우선 확인하세요.

실습 1 · 13분

문서 초안, 3분 만에

목표셋 중 하나를 골라 초안을 받고, 이어서 한 번 더 고쳐 달라고 요청합니다.
사립학교 행정실 주무관의 문서 작성을 도와줘.
아래 내용으로 내부 결재용 지출품의 기안문 초안을 써줘.
- 건명: 【교무실 복합기 토너 구입】
- 목적: 【교무실 업무용 소모품 보충】
- 금액: 【약 50만 원】
형식: 1. 목적 2. 세부내용(표) 3. 소요예산 4. 붙임
공문서 문체로 쓰고, 모르는 정보는 지어내지 말고 【확인 필요】로 표시해줘.
【현장체험학습 취소】에 따른 【참가비】 환불을 학부모에게 안내하는 글을 써줘.
- 정중하고 이해하기 쉽게
- 환불 금액, 일정, 방법은 【 】 빈칸으로 남겨줘
- 가정통신문 버전과 문자메시지(90자 이내) 버전 두 가지로
납품 업체가 "대금 지급이 왜 이렇게 늦냐"고 항의 전화를 했어.
【검수 완료 후 결재 절차를 거쳐 지급】된다는 점을 정중하게 설명하는 답변을 만들어줘.
구성: 공감 한 문장 → 절차 안내 → 다음 단계 안내
전화 응대용 말투와 문자 답장용 두 가지로 써줘.

실습 2 · 5분

AI는 그럴듯하게 틀린다

목표같은 질문을 옆 사람과 함께 보내고, 두 답이 같은지 비교합니다. Gemini와 ChatGPT를 쓰는 사람끼리 짝이면 더 좋습니다.
질문 1
사학기관 재무·회계 규칙에서 수의계약이 가능한 금액 기준을
공사·물품·용역별로 알려주고, 근거 조항 번호도 적어줘.
질문 2 (같은 대화에 이어서)
방금 답한 조항 번호와 금액을 다시 점검해줘.
확실하지 않은 부분은 [불확실]이라고 표시해줘.

비교해 보세요

  • 옆 사람과 금액이 같은가요?
  • 조항 번호가 같은가요?
  • 질문 2에서 스스로 고친 부분이 있나요?
정답은 원문에 있습니다. 법령·금액·조항은 AI에게 묻고, 국가법령정보센터 원문으로 확인합니다.

실습 3 · 15분

견적서 사진 세 장, 비교표 하나

목표아래 견적서 3장을 화면 캡처(또는 대강당 스크린 촬영)해서 한 번에 첨부하고 비교표를 받습니다.
첨부한 견적서 사진들을 읽고 업체별 비교표를 만들어줘.
열: 업체명 / 품목 / 수량 / 단가 / 공급가액 / 부가세 / 합계 / 납품기한
- 읽기 어려운 값은 추측하지 말고 '판독 불가'로 표시
- 표 아래에 최저가 업체를 알려주고,
  단가×수량이나 합계 계산이 맞지 않는 곳이 있으면 지적해줘.
